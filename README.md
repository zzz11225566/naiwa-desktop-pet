# 奶蛙桌面宠物

奶蛙是一个运行在 Windows 桌面上的 2D 宠物，直接使用文件夹中的原始图片作为形象。双击 `release/奶蛙.exe` 后，它会从屏幕右下角出现。

## 交互

- 左键单击：随机切到一张保存好的动作原图，平滑过渡，保持几秒后再平滑回到待机图。
- 左键拖动：拖动奶蛙到桌面任意位置。
- 右键单击或左键双击：打开控制面板。
- 控制面板：调整大小（最大为屏幕高度的一半），以及“上移 / 下移”切换奶蛙是否置顶显示。
- 静止状态：显示待机原图，并带有轻微呼吸动画；眼睛区域保留原图中的白色，不会被背景透明化误删。

## 技术说明

奶蛙使用 WPF 2D 动画构建。原始图片先经过边界连通域处理，只移除与图片边缘相连的背景，保留奶蛙眼睛和身体高光中的白色。处理后的透明 PNG 直接嵌入 exe，所以发布物仍是单个文件。

待机图使用 `1cf29af9d41f68214ee0685836edeb15.png`，其余 8 张原图作为动作帧。图片路径与资源名在 `src/NaiWa.cs` 中定义。

## 构建

需要 Windows 和 .NET Framework 4.x。在 PowerShell 中执行：

```powershell
运行 `src/rebuild_2d.ps1` 会重新编译并打包所有图片资源。
```

图标生成脚本为 `build/make_icon.ps1`，会从参考图片中裁出奶蛙上半身并生成 `app.ico`。背景透明化工具为 `build/BgRemover.cs`。
