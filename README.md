# 奶蛙桌面宠物

奶蛙是一个运行在 Windows 桌面上的 2D 宠物，直接使用文件夹中的原始图片作为形象。双击 `release/奶蛙.exe` 后，它会从屏幕右下角出现。

## 交互

- 左键单击：奶蛙执行随机动作。动作不是切图，而是通过 2D 骨骼蒙皮带动躯干和四肢变形，平滑过渡后保持数秒，再回到待机图。
- 左键拖动：拖动奶蛙到桌面任意位置。
- 右键单击或左键双击：打开控制面板。
- 控制面板：调整大小（最大为屏幕高度的一半），以及“上移 / 下移”切换奶蛙是否置顶显示。
- 静止状态：随机显示“正面 / 侧身站立 / 背面”三张待机原图，并带有轻微呼吸动画；眼睛区域保留原图中的白色，不会被背景透明化误删。

## 技术说明

奶蛙使用 WPF 2D 骨骼动画构建。原始图片先经过边界连通域处理，只移除与图片边缘相连的背景，保留奶蛙眼睛和身体高光中的白色。处理后的透明 PNG 直接嵌入 exe，所以发布物仍是单个文件。

待机图使用 `正面.png`、`侧身站立.png`、`背面.png`。动作状态使用 `飞起来.png`、`挥手.png`、`跑步.png`、`试探.png`、`舞蹈.png`、`扎马步.png` 的语义来驱动骨骼目标姿势。

“上移 / 下移”使用 Win32 `SetWindowPos` 强制切换 `HWND_TOPMOST` 和 `HWND_NOTOPMOST`，因此下移后奶蛙会被 ChatGPT 等普通窗口覆盖。

## 构建

需要 Windows 和 .NET Framework 4.x。在 PowerShell 中执行：

```powershell
运行 `src/rebuild_2d.ps1` 会重新编译并打包所有图片资源。
```

图标生成脚本为 `build/make_icon.ps1`，会从参考图片中裁出奶蛙上半身并生成 `app.ico`。背景透明化工具为 `build/BgRemover.cs`。
